# 项目简介和核心功能

FastD\Config 是一个轻量级的 PHP 配置解析器，用于简化配置文件的加载、解析和访问。它提供了一套简洁的 API，支持多种常见的配置文件格式，并具备强大的变量替换功能。

## 项目简介

FastD\Config 是 FastD 框架生态系统中的一个组件库，专注于配置管理。该项目的目标是提供一个简单、高效、易用的配置解析工具，支持多种配置文件格式，并提供便捷的配置访问方式。

### 项目特点

- **多格式支持**：支持 JSON、YAML、INI 和 PHP 配置文件格式
- **变量替换**：支持使用 `%variable_name%` 语法进行变量替换
- **嵌套访问**：支持使用点号分隔的键路径访问嵌套配置
- **数组式访问**：实现 ArrayAccess 接口，支持数组式操作
- **轻量级**：代码简洁，依赖最少，易于集成

## 核心功能

### 1. 配置文件解析

FastD\Config 支持多种常见的配置文件格式：

- **JSON**：标准的 JSON 格式配置文件
- **YAML**：人类可读的 YAML 格式配置文件
- **INI**：传统的 INI 格式配置文件
- **PHP**：PHP 数组返回格式的配置文件

### 2. 变量替换机制

变量替换是 FastD\Config 的一个重要特性，允许在配置文件中使用占位符，并在解析时用实际值替换。变量使用 `%` 符号标记，例如 `%database.host%`。

### 3. 嵌套配置访问

支持使用点号分隔的键路径访问嵌套的配置值。例如，对于配置 `['database' => ['host' => 'localhost']]`，可以使用 `database.host` 访问 `localhost` 值。

### 4. 配置合并

提供配置合并功能，可以将多个配置源合并到一个配置对象中，便于管理复杂的配置结构。

### 5. 数组式操作

实现了 ArrayAccess 接口，允许像操作数组一样操作配置对象，提供更直观的使用体验。

## 应用场景

FastD\Config 适用于以下场景：

- **Web 框架配置管理**：为 Web 框架提供统一的配置管理方案
- **应用程序配置**：管理应用程序的各种配置参数
- **微服务配置**：在微服务架构中统一管理服务配置
- **环境变量注入**：通过变量替换机制注入环境特定的配置值
- **多环境配置**：支持不同环境（开发、测试、生产）的配置管理

## 设计哲学

FastD\Config 遵循以下设计原则：

- **简洁性**：API 设计简洁直观，易于理解和使用
- **一致性**：不同格式的配置文件提供一致的访问接口
- **灵活性**：支持多种配置格式和访问方式
- **可扩展性**：易于扩展和定制
- **性能**：高效解析和访问配置数据

通过这些核心功能和设计原则，FastD\Config 提供了一个强大而灵活的配置管理解决方案，适用于各种 PHP 应用程序。
