# 主要组件介绍

FastD\Config 库主要由两个核心组件构成：`FileParser` 和 `Parsed`。这两个组件协同工作，提供了完整的配置解析和管理功能。

## FileParser 类

`FileParser` 是配置解析的主要入口类，负责加载和解析不同格式的配置文件。

### 类定义

```php
class FileParser
{
    public Parsed $var;
    public Parsed $parsed;

    public function __construct(array|string $vars = [], public Parsed $parsed = new Parsed());
    public function load(string $file): array;
    public function parse(string $file): Parsed;
    protected function replace(mixed $data): mixed;
}
```

### 属性说明

- **`$var`**：`Parsed` 类型，存储变量配置，用于变量替换功能
- **`$parsed`**：`Parsed` 类型，存储解析后的配置数据

### 构造函数

```php
public function __construct(array|string $vars = [], public Parsed $parsed = new Parsed())
```

**参数说明：**
- `$vars`：数组或字符串类型，可以是变量数组或变量配置文件路径
- `$parsed`：`Parsed` 对象，用于存储解析后的配置（可选）

**功能说明：**
- 如果 `$vars` 是字符串，则将其视为配置文件路径并加载
- 如果 `$vars` 是数组，则直接使用该数组作为变量配置
- 初始化 `$var` 属性为包含变量数据的 `Parsed` 对象

### load 方法

```php
public function load(string $file): array
```

**功能说明：**
- 根据文件扩展名自动识别配置文件格式
- 支持四种格式：JSON、YAML、INI、PHP
- 返回解析后的数组数据

**格式支持：**
- `.json`：使用 `json_decode()` 解析
- `.yml`：使用 `Yaml::parseFile()` 解析
- `.ini`：使用 `parse_ini_file()` 解析
- `.php`：使用 `include` 语句加载
- 其他格式：抛出异常

### parse 方法

```php
public function parse(string $file): Parsed
```

**功能说明：**
- 加载指定文件的配置
- 对加载的配置执行变量替换
- 将解析后的配置合并到 `$parsed` 对象中
- 返回包含解析后配置的 `Parsed` 对象

### replace 方法

```php
protected function replace(mixed $data): mixed
```

**功能说明：**
- 递归处理数据中的变量替换
- 支持字符串、数组和混合数据类型
- 使用正则表达式匹配 `%variable_name%` 格式的变量
- 在 `$var` 中查找对应的变量值进行替换

## Parsed 类

`Parsed` 类继承自 PHP 的 `ArrayObject`，提供了便捷的配置访问功能。

### 类定义

```php
class Parsed extends ArrayObject
{
    public function merge(array $parsed): self;
    public function get(string $key, mixed $default = null): mixed;
    public function set(string $key, mixed $value): void;
    public function has(string $key): bool;
    public function unset(string $key): void;
    
    // ArrayAccess 接口方法
    public function offsetGet($key): mixed;
    public function offsetSet($key, $value): void;
    public function offsetExists($key): bool;
    public function offsetUnset($key): void;
}
```

### merge 方法

```php
public function merge(array $parsed): self
```

**功能说明：**
- 将传入的数组与当前配置合并
- 支持深度合并嵌套数组
- 当键已存在且值为数组时，进行递归合并
- 返回当前对象以支持链式调用

**合并规则：**
- 如果原值和新值都是数组，则递归合并
- 如果原值不是数组但新值是数组，则将原值转换为数组再合并
- 如果键为字符串，则直接赋值
- 如果键为数字，则追加到数组末尾

### get 方法

```php
public function get(string $key, mixed $default = null): mixed
```

**功能说明：**
- 支持点号分隔的嵌套键访问
- 如果键存在直接匹配，则返回该键的值
- 如果键包含点号，则按路径访问嵌套值
- 如果路径不存在，则返回默认值

**访问规则：**
- 优先检查直接键是否存在
- 如果不存在且键包含点号，则按路径解析访问
- 逐级检查路径中每个键是否存在
- 返回最终路径的值或默认值

### set 方法

```php
public function set(string $key, mixed $value): void
```

**功能说明：**
- 设置配置值，支持点号分隔的嵌套键
- 如果键存在直接匹配，则直接设置该键的值
- 如果键包含点号，则按路径设置嵌套值
- 自动创建必要的嵌套结构

**设置规则：**
- 优先检查直接键是否存在
- 如果不存在且键包含点号，则按路径解析设置
- 自动创建中间层级的数组结构
- 支持设置任意类型的数据

### has 方法

```php
public function has(string $key): bool
```

**功能说明：**
- 检查配置键是否存在
- 支持点号分隔的嵌套键检查
- 如果键存在直接匹配，则返回 true
- 如果键包含点号，则检查路径是否存在

**检查规则：**
- 优先检查直接键是否存在
- 如果不存在且键包含点号，则按路径检查
- 逐级验证路径中每个键是否存在
- 只有路径完全存在才返回 true

### unset 方法

```php
public function unset(string $key): void
```

**功能说明：**
- 删除配置键，支持点号分隔的嵌套键删除
- 如果键不包含点号，则直接删除该键
- 如果键包含点号，则按路径删除嵌套值

**删除规则：**
- 如果键不包含点号，直接调用父类的 `offsetUnset`
- 如果键包含点号，则按路径定位并删除目标值
- 保持其他配置数据不变

### ArrayAccess 接口方法

`Parsed` 类实现了 `ArrayAccess` 接口，提供数组式访问功能：

- **`offsetGet($key)`**：调用 `get($key, null)` 方法
- **`offsetSet($key, $value)`**：调用 `set($key, $value)` 方法
- **`offsetExists($key)`**：调用 `has($key)` 方法
- **`offsetUnset($key)`**：调用 `unset($key)` 方法

## 组件协作关系

### FileParser 与 Parsed 的协作

1. **初始化阶段**：
   - `FileParser` 在构造函数中创建 `Parsed` 对象存储变量配置
   - 提供一个主 `Parsed` 对象用于存储解析后的配置

2. **解析阶段**：
   - `FileParser::load()` 加载配置文件并返回数组
   - `FileParser::replace()` 在加载的数据中执行变量替换
   - 替换后的数据通过 `Parsed::merge()` 合并到主配置对象

3. **访问阶段**：
   - 用户通过 `Parsed` 对象访问配置数据
   - 支持方法调用和数组式访问

### 使用示例

```php
use FastD\Config\FileParser;

// 创建解析器实例
$parser = new FileParser([
    'database_host' => 'localhost',
    'database_port' => 3306
]);

// 解析配置文件
$config = $parser->parse('config.json');

// 访问配置
echo $config->get('database.host'); // 访问嵌套配置
$config['database.host'];           // 数组式访问
```

这种设计使得 `FileParser` 和 `Parsed` 各司其职，`FileParser` 负责配置文件的加载和解析，`Parsed` 负责配置数据的存储和访问，共同提供了一个功能强大且易于使用的配置管理解决方案。
