# 技术栈和架构设计

## 技术栈

FastD\Config 采用现代 PHP 技术栈，确保了高性能和良好的兼容性。

### PHP 版本要求

- **最低版本**：PHP 8.2+
- **推荐版本**：PHP 8.2 或更高版本
- **严格类型**：使用 `declare(strict_types=1)` 确保类型安全

### 依赖库

FastD\Config 依赖以下第三方库：

- **symfony/yaml**：用于解析 YAML 格式的配置文件
  - 版本要求：^8.0
  - 功能：提供强大的 YAML 解析和生成能力

- **ext-json**：PHP 内置的 JSON 扩展
  - 功能：用于解析和生成 JSON 格式的配置文件

### 开发依赖

- **phpunit/phpunit**：用于单元测试
  - 版本要求：^9.0
  - 功能：确保代码质量和功能正确性

## 架构设计

FastD\Config 采用面向对象的设计模式，主要包含两个核心类：

### 1. FileParser 类

`FileParser` 是主要的配置文件解析器类，负责加载和解析不同格式的配置文件。

#### 核心职责

- 加载配置文件（支持 JSON、YAML、INI、PHP 格式）
- 执行变量替换功能
- 解析配置文件并返回 Parsed 对象

#### 关键特性

- **多格式支持**：通过 `match` 表达式识别文件扩展名并使用相应的解析方法
- **变量替换**：内置变量替换机制，支持 `%variable_name%` 语法
- **配置合并**：将解析后的配置合并到 Parsed 对象中

### 2. Parsed 类

`Parsed` 类继承自 PHP 的 `ArrayObject`，提供了便捷的配置访问功能。

#### 核心职责

- 提供数组式的配置访问接口
- 支持点号分隔的嵌套键访问
- 实现配置的增、删、改、查操作
- 支持配置合并功能

#### 关键特性

- **ArrayAccess 实现**：实现 `ArrayAccess` 接口，支持数组式操作
- **嵌套访问**：支持 `database.host` 形式的嵌套配置访问
- **类型安全**：使用严格类型声明确保类型安全
- **链式操作**：支持链式调用模式

## 设计模式

### 组合模式

`FileParser` 和 `Parsed` 之间采用组合模式，`FileParser` 包含 `Parsed` 对象，共同完成配置解析任务。

### 适配器模式

通过适配不同的文件解析方法（`json_decode`、`Yaml::parseFile`、`parse_ini_file`、`include`），为不同格式的配置文件提供统一的访问接口。

## 架构优势

### 模块化设计

- 各组件职责明确，便于维护和扩展
- 松耦合设计，降低模块间的依赖关系

### 易扩展性

- 新增配置格式只需在 `load` 方法中添加相应的解析逻辑
- 可通过继承 `Parsed` 类扩展配置访问功能

### 性能优化

- 使用 PHP 内置函数进行配置解析，确保性能
- 通过引用传递减少内存开销
- 高效的变量替换算法

## 类关系图

```
FileParser
├── Parsed (parsed)
├── Parsed (var)
├── load(string $file): array
├── parse(string $file): Parsed
└── replace(mixed $data): mixed

Parsed extends ArrayObject
├── merge(array $parsed): self
├── get(string $key, mixed $default = null): mixed
├── set(string $key, mixed $value): void
├── has(string $key): bool
├── unset(string $key): void
├── offsetGet($key): mixed
├── offsetSet($key, $value): void
├── offsetExists($key): bool
└── offsetUnset($key): void
```

## 扩展性考虑

FastD\Config 的架构设计考虑了未来的扩展需求：

- **格式扩展**：可以轻松添加新的配置文件格式支持
- **功能扩展**：可以通过继承或组合扩展配置处理功能
- **插件机制**：为未来可能的插件系统预留接口

这种架构设计确保了 FastD\Config 既满足当前需求，又具备良好的可扩展性，能够适应未来的发展需要。
