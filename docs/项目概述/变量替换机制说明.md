# 变量替换机制说明

FastD\Config 提供了强大的变量替换功能，允许在配置文件中使用占位符，并在解析时用实际值替换。这种机制使得配置更加灵活，便于在不同环境中使用相同的配置模板。

## 变量语法

### 基本语法

变量使用 `%` 符号进行标记，格式为 `%variable_name%`。变量名可以包含字母、数字、点号和下划线。

**示例：**
```yaml
# config.yml
database:
  host: "%database_host%"
  port: "%database_port%"
  name: "%database_name%"
  url: "mysql://%database_user%:%database_password%@%database_host%:%database_port%/%database_name%"
```

### 变量命名规则

- 变量名可以包含字母、数字、点号（.）和下划线（_）
- 变量名区分大小写
- 变量名不能包含空格或其他特殊字符
- 支持嵌套路径访问，如 `database.host`

## 变量替换原理

### 替换过程

变量替换在 `FileParser::replace()` 方法中执行，过程如下：

1. **递归遍历**：遍历整个配置数组，包括嵌套结构
2. **字符串识别**：识别包含 `%` 符号的字符串
3. **模式匹配**：使用正则表达式 `/([a-zA-Z0-9._]+)/` 匹配变量
4. **值查找**：在变量配置中查找对应的值
5. **值替换**：将变量占位符替换为实际值

### 替换算法

```php
protected function replace(mixed $data): mixed
{
    return match (true) {
        is_array($data) => array_map(
            fn ($value) => $this->replace($value),
            $data
        ),
        is_string($data) => preg_replace_callback(
            '/%([a-zA-Z0-9._]+)%/',
            fn($matches) => $this->var->get($matches[1], $matches[0]),
            $data
        ),
        default => $data,
    };
}
```

**算法说明：**
- 对数组类型数据：递归处理每个元素
- 对字符串类型数据：执行变量替换
- 对其他类型数据：直接返回

## 变量配置方式

### 1. 构造函数传入数组

```php
use FastD\Config\FileParser;

$variables = [
    'database_host' => 'localhost',
    'database_port' => 3306,
    'database_name' => 'myapp',
    'database_user' => 'root',
    'database_password' => 'password'
];

$parser = new FileParser($variables);
$config = $parser->parse('config.yml');
```

### 2. 构造函数传入配置文件

```php
$parser = new FileParser('variables.yml');
$config = $parser->parse('config.yml');
```

**variables.yml 示例：**
```yaml
database_host: localhost
database_port: 3306
database_name: myapp
database_user: root
database_password: password
```

## 替换行为说明

### 1. 变量存在时的替换

当变量在配置中存在时，占位符会被实际值替换：

**原始配置：**
```yaml
database:
  host: "%database_host%"
  port: "%database_port%"
```

**变量配置：**
```php
[
    'database_host' => '192.168.1.100',
    'database_port' => 5432
]
```

**替换后：**
```yaml
database:
  host: "192.168.1.100"
  port: 5432
```

### 2. 变量不存在时的处理

当变量在配置中不存在时，占位符保持不变：

**原始配置：**
```yaml
database:
  host: "%unknown_host%"
  port: "%database_port%"
```

**变量配置：**
```php
[
    'database_port' => 5432
]
```

**替换后：**
```yaml
database:
  host: "%unknown_host%"  # 未替换
  port: 5432              # 已替换
```

### 3. 嵌套变量替换

支持在变量值中使用其他变量：

```yaml
database_url: "mysql://%database_user%:%database_password%@%database_host%:%database_port%/%database_name%"
database_host: "%db_host%"
```

## 复杂场景处理

### 1. 多次替换

支持在同一个字符串中包含多个变量：

```yaml
connection_string: "%protocol%://%username%:%password%@%host%:%port%"
```

### 2. 混合内容替换

变量可以嵌入到其他文本中：

```yaml
greeting: "Hello, %user_name%! Welcome to %app_name%."
```

### 3. 嵌套配置中的变量替换

变量替换适用于配置的任何层级：

```yaml
database:
  connections:
    mysql:
      host: "%mysql_host%"
      port: "%mysql_port%"
    redis:
      host: "%redis_host%"
      port: "%redis_port%"
```

## 实际应用示例

### 环境配置管理

```php
// 根据环境设置变量
$env = $_ENV['APP_ENV'] ?? 'development';

$variables = match($env) {
    'production' => [
        'database_host' => 'prod-db.example.com',
        'redis_host' => 'prod-redis.example.com',
        'api_url' => 'https://api.example.com'
    ],
    'staging' => [
        'database_host' => 'staging-db.example.com',
        'redis_host' => 'staging-redis.example.com',
        'api_url' => 'https://staging-api.example.com'
    ],
    default => [
        'database_host' => 'localhost',
        'redis_host' => 'localhost',
        'api_url' => 'http://localhost:8000'
    ]
};

$parser = new FileParser($variables);
$config = $parser->parse('app.yml');
```

### 配置模板

创建通用配置模板，通过变量适配不同环境：

```yaml
# template.yml
database:
  host: "%db_host%"
  port: "%db_port%"
  username: "%db_username%"
  password: "%db_password%"
  database: "%db_name%"

cache:
  host: "%cache_host%"
  port: "%cache_port%"

logging:
  level: "%log_level%"
  path: "%log_path%"
```

## 最佳实践

### 1. 变量命名规范

- 使用有意义的变量名
- 采用一致的命名约定（如 snake_case）
- 避免过于复杂的嵌套路径

### 2. 默认值处理

在变量配置中提供合理的默认值：

```php
$defaultVariables = [
    'database_host' => 'localhost',
    'database_port' => 3306,
    'log_level' => 'info'
];
$variables = array_merge($defaultVariables, $envVariables);
```

### 3. 安全考虑

- 敏感信息（如密码）应通过环境变量传入
- 避免在配置文件中硬编码敏感信息
- 考虑对敏感变量进行加密处理

### 4. 调试和日志

在开发环境中可以记录变量替换过程：

```php
// 记录替换前后的配置
$original = $parser->load('config.yml');
$replaced = $parser->replace($original);
error_log('Config before replacement: ' . json_encode($original));
error_log('Config after replacement: ' . json_encode($replaced));
```

通过这种灵活的变量替换机制，FastD\Config 能够适应各种复杂的配置需求，使配置管理更加便捷和高效。
