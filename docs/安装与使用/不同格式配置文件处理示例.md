# 不同格式配置文件处理示例

## JSON 格式配置

JSON (JavaScript Object Notation) 是一种轻量级的数据交换格式，易于人阅读和编写，同时也易于机器解析和生成。

### JSON 配置文件示例

创建 `config/app.json`：

```json
{
    "app": {
        "name": "My Application",
        "version": "1.0.0",
        "debug": true,
        "timezone": "Asia/Shanghai"
    },
    "database": {
        "host": "localhost",
        "port": 3306,
        "name": "myapp",
        "credentials": {
            "username": "root",
            "password": "password"
        },
        "options": {
            "charset": "utf8mb4",
            "collation": "utf8mb4_unicode_ci"
        }
    },
    "features": [
        "auth",
        "cache",
        "logging",
        "monitoring"
    ],
    "limits": {
        "max_file_size": 10485760,
        "max_request_size": 52428800
    }
}
```

### JSON 配置处理

```php
<?php
require_once 'vendor/autoload.php';

use FastD\Config\FileParser;

// 创建解析器并加载 JSON 配置
$parser = new FileParser();
$config = $parser->parse('config/app.json');

// 访问不同类型的值
echo $config->get('app.name') . "\n";           // My Application
echo $config->get('app.debug') . "\n";          // 1 (true)
echo $config->get('database.host') . "\n";      // localhost
echo $config->get('database.port') . "\n";      // 3306

// 访问嵌套对象
echo $config->get('database.credentials.username') . "\n";  // root

// 访问数组
$features = $config->get('features');
print_r($features);

// 访问数值
$maxFileSize = $config->get('limits.max_file_size');
echo "Max file size: " . $maxFileSize . "\n";   // 10485760
```

### JSON 配置的优缺点

**优点：**
- 结构清晰，易于理解
- 广泛支持，几乎所有编程语言都支持
- 数据类型丰富（字符串、数字、布尔值、数组、对象）

**缺点：**
- 不支持注释
- 语法严格，容易出现格式错误
- 对于复杂配置可能显得冗长

## YAML 格式配置

YAML (YAML Ain't Markup Language) 是一种人类可读的数据序列化语言，常用于配置文件。

### YAML 配置文件示例

创建 `config/app.yml`：

```yaml
app:
  name: "My Application"
  version: "1.0.0"
  debug: true
  timezone: "Asia/Shanghai"
  # 这是注释，YAML 支持注释
  metadata:
    author: "Developer"
    license: "MIT"
    description: >
      这是一个多行
      描述示例

database:
  host: localhost
  port: 3306
  name: myapp
  credentials:
    username: root
    password: password
  options:
    charset: utf8mb4
    collation: utf8mb4_unicode_ci
    # SSL 选项
    ssl:
      enabled: false
      cert: /path/to/cert
      key: /path/to/key

features:
  - auth
  - cache
  - logging
  - monitoring

limits:
  max_file_size: 10485760
  max_request_size: 52428800

# 环境特定配置
environments:
  development:
    debug: true
    log_level: debug
  production:
    debug: false
    log_level: error
```

### YAML 配置处理

```php
<?php
require_once 'vendor/autoload.php';

use FastD\Config\FileParser;

// 创建解析器并加载 YAML 配置
$parser = new FileParser();
$config = $parser->parse('config/app.yml');

// 访问基本配置
echo $config->get('app.name') . "\n";           // My Application
echo $config->get('app.debug') . "\n";          // 1 (true)

// 访问嵌套配置
echo $config->get('database.credentials.username') . "\n";  // root

// 访问多行文本
echo $config->get('app.metadata.description') . "\n";

// 访问环境特定配置
$env = 'production';
echo $config->get("environments.{$env}.log_level") . "\n";  // error

// 访问 SSL 配置
$sslEnabled = $config->get('database.options.ssl.enabled');
echo $sslEnabled ? 'SSL Enabled' : 'SSL Disabled';
```

### YAML 配置的优缺点

**优点：**
- 人类可读性极佳
- 支持注释
- 语法灵活，支持多行文本
- 结构清晰，缩进明确

**缺点：**
- 缩进敏感，容易出错
- 需要额外的解析库（symfony/yaml）
- 在某些情况下解析可能较慢

## INI 格式配置

INI 是一种简单的配置文件格式，最初用于 Windows 系统，现在广泛用于各种应用程序。

### INI 配置文件示例

创建 `config/app.ini`：

```ini
; 应用程序配置
[app]
name = My Application
version = 1.0.0
debug = 1
timezone = Asia/Shanghai

; 数据库配置
[database]
host = localhost
port = 3306
name = myapp
username = root
password = password
charset = utf8mb4
collation = utf8mb4_unicode_ci

; 特性开关
[features]
auth = 1
cache = 1
logging = 1
monitoring = 1

; 限制设置
[limits]
max_file_size = 10485760
max_request_size = 52428800

; 邮件配置
[mail]
smtp_host = smtp.example.com
smtp_port = 587
smtp_username = user@example.com
smtp_password = password
from_address = noreply@example.com
```

### INI 配置处理

```php
<?php
require_once 'vendor/autoload.php';

use FastD\Config\FileParser;

// 创建解析器并加载 INI 配置
$parser = new FileParser();
$config = $parser->parse('config/app.ini');

// 注意：INI 格式会将节（section）作为顶级键
echo $config->get('app.name') . "\n";           // My Application
echo $config->get('app.debug') . "\n";          // 1
echo $config->get('database.host') . "\n";      // localhost

// 访问邮件配置
echo $config->get('mail.smtp_host') . "\n";     // smtp.example.com

// INI 格式处理数组（需要特殊处理）
$features = [];
foreach (['auth', 'cache', 'logging', 'monitoring'] as $feature) {
    if ($config->get("features.{$feature}") == 1) {
        $features[] = $feature;
    }
}
print_r($features);
```

### INI 配置的优缺点

**优点：**
- 格式简单，易于理解
- PHP 内置支持解析
- 适合简单的键值对配置

**缺点：**
- 不支持复杂嵌套结构
- 数据类型有限（主要是字符串）
- 不支持注释嵌套结构

## PHP 格式配置

PHP 格式配置文件实际上是 PHP 代码，返回一个数组配置。

### PHP 配置文件示例

创建 `config/app.php`：

```php
<?php
// config/app.php
return [
    'app' => [
        'name' => 'My Application',
        'version' => '1.0.0',
        'debug' => true,
        'timezone' => 'Asia/Shanghai',
        'metadata' => [
            'author' => 'Developer',
            'license' => 'MIT',
            'description' => 'PHP 格式的配置文件示例'
        ]
    ],
    'database' => [
        'host' => 'localhost',
        'port' => 3306,
        'name' => 'myapp',
        'credentials' => [
            'username' => 'root',
            'password' => 'password'
        ],
        'options' => [
            'charset' => 'utf8mb4',
            'collation' => 'utf8mb4_unicode_ci',
            'ssl' => [
                'enabled' => false,
                'cert' => '/path/to/cert',
                'key' => '/path/to/key'
            ]
        ]
    ],
    'features' => [
        'auth',
        'cache', 
        'logging',
        'monitoring'
    ],
    'limits' => [
        'max_file_size' => 10485760,
        'max_request_size' => 52428800
    ],
    // 可以包含 PHP 代码逻辑
    'environment' => $_ENV['APP_ENV'] ?? 'development',
    // 动态配置
    'cache_dir' => sys_get_temp_dir() . '/myapp_cache',
    // 常量使用
    'upload_max_filesize' => ini_get('upload_max_filesize'),
];
```

### PHP 配置处理

```php
<?php
require_once 'vendor/autoload.php';

use FastD\Config\FileParser;

// 创建解析器并加载 PHP 配置
$parser = new FileParser();
$config = $parser->parse('config/app.php');

// 访问配置值
echo $config->get('app.name') . "\n";           // My Application
echo $config->get('database.host') . "\n";      // localhost
echo $config->get('environment') . "\n";        // development (或环境变量值)

// 访问动态生成的配置
echo $config->get('cache_dir') . "\n";          // 系统临时目录下的路径

// PHP 格式支持复杂逻辑
$features = $config->get('features');
echo "Enabled features: " . implode(', ', $features) . "\n";
```

### PHP 配置的优缺点

**优点：**
- 支持完整的 PHP 语法和逻辑
- 可以动态生成配置值
- 数据类型完全支持
- 性能通常最好（直接执行 PHP 代码）

**缺点：**
- 安全风险（执行任意 PHP 代码）
- 不适合非技术用户编辑
- 可能包含复杂逻辑，难以维护

## 多格式配置组合使用

### 配置文件分离策略

在实际项目中，通常会将不同类型的配置分离到不同的文件中：

```php
<?php
require_once 'vendor/autoload.php';

use FastD\Config\FileParser;

class ConfigManager
{
    private $parser;
    private $config;
    
    public function __construct()
    {
        $this->parser = new FileParser();
        $this->loadConfigurations();
    }
    
    private function loadConfigurations()
    {
        // 基础配置 - YAML 格式（人类可读）
        $this->parser->parse('config/base.yml');
        
        // 数据库配置 - PHP 格式（支持动态逻辑）
        $this->parser->parse('config/database.php');
        
        // 环境配置 - JSON 格式（结构化）
        $environment = $_ENV['APP_ENV'] ?? 'development';
        $this->parser->parse("config/{$environment}.json");
        
        // 覆盖配置 - INI 格式（简单键值对）
        $this->parser->parse('config/overrides.ini');
        
        $this->config = $this->parser->parsed;
    }
    
    public function get($key, $default = null)
    {
        return $this->config->get($key, $default);
    }
    
    public function has($key)
    {
        return $this->config->has($key);
    }
}

// 使用配置管理器
$configManager = new ConfigManager();
$dbHost = $configManager->get('database.host');
$appName = $configManager->get('app.name');
```

### 格式选择建议

根据不同的使用场景选择合适的配置格式：

1. **开发环境配置**：YAML - 便于阅读和修改
2. **生产环境配置**：JSON - 结构清晰，易于自动化处理
3. **数据库配置**：PHP - 支持动态连接参数
4. **简单键值对**：INI - 格式简单，易于理解
5. **复杂业务逻辑**：PHP - 支持条件配置

## 错误处理和验证

### 不同格式的错误处理

```php
<?php
use FastD\Config\FileParser;

function loadConfigWithFallback($primaryFile, $fallbackFile)
{
    $parser = new FileParser();
    
    try {
        return $parser->parse($primaryFile);
    } catch (Exception $e) {
        echo "主配置文件加载失败: " . $e->getMessage() . "\n";
        echo "尝试加载备用配置文件: {$fallbackFile}\n";
        
        try {
            return $parser->parse($fallbackFile);
        } catch (Exception $e2) {
            echo "备用配置文件也加载失败: " . $e2->getMessage() . "\n";
            // 返回默认配置
            return new \FastD\Config\Parsed([
                'database' => [
                    'host' => 'localhost',
                    'port' => 3306
                ]
            ]);
        }
    }
}

// 使用示例
$config = loadConfigWithFallback('config/app.yml', 'config/default.json');
```

### 配置格式验证

```php
<?php
use FastD\Config\FileParser;

class ConfigValidator
{
    public static function validateFormat($file)
    {
        $extension = pathinfo($file, PATHINFO_EXTENSION);
        
        switch ($extension) {
            case 'json':
                return self::validateJson($file);
            case 'yml':
            case 'yaml':
                return self::validateYaml($file);
            case 'ini':
                return self::validateIni($file);
            case 'php':
                return self::validatePhp($file);
            default:
                throw new InvalidArgumentException("不支持的配置格式: {$extension}");
        }
    }
    
    private static function validateJson($file)
    {
        $content = file_get_contents($file);
        $data = json_decode($content, true);
        return json_last_error() === JSON_ERROR_NONE && is_array($data);
    }
    
    private static function validateYaml($file)
    {
        try {
            \Symfony\Component\Yaml\Yaml::parseFile($file);
            return true;
        } catch (\Exception $e) {
            return false;
        }
    }
    
    private static function validateIni($file)
    {
        return parse_ini_file($file, true) !== false;
    }
    
    private static function validatePhp($file)
    {
        // 检查文件语法
        $syntax = shell_exec("php -l " . escapeshellarg($file));
        return strpos($syntax, 'No syntax errors') !== false;
    }
}

// 验证配置文件
if (ConfigValidator::validateFormat('config/app.yml')) {
    $parser = new FileParser();
    $config = $parser->parse('config/app.yml');
    echo "配置文件验证通过并成功加载\n";
} else {
    echo "配置文件格式验证失败\n";
}
```
