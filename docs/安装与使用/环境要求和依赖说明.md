# 环境要求和依赖说明

## 系统要求

### PHP 版本要求

FastD\Config 需要以下 PHP 版本：

- **最低版本**: PHP 8.2
- **推荐版本**: PHP 8.2 或更高版本
- **支持版本**: PHP 8.2, 8.3, 8.4（建议使用最新稳定版本）

### PHP 扩展要求

FastD\Config 依赖以下 PHP 扩展：

- **ext-json**: PHP 内置的 JSON 扩展，用于解析和生成 JSON 格式的配置文件
  - 大部分 PHP 安装都默认包含此扩展
  - 如果缺失，需要在编译 PHP 时启用或在配置中加载

### 系统资源要求

- **内存**: 最低 16MB 可用内存（推荐 32MB 或更多）
- **磁盘空间**: 需要约 2MB 空间用于安装
- **文件权限**: 需要读取配置文件的权限

## 依赖库说明

FastD\Config 依赖以下第三方库：

### 主要依赖

- **symfony/yaml** 
  - 版本要求: ^8.0
  - 功能: 用于解析 YAML 格式的配置文件
  - 用途: 提供强大的 YAML 解析和生成能力
  - 安装大小: 约 150KB

### 开发依赖

- **phpunit/phpunit**
  - 版本要求: ^9.0
  - 功能: 用于单元测试
  - 用途: 确保代码质量和功能正确性
  - 仅在开发环境需要

## 环境兼容性

### 操作系统兼容性

FastD\Config 在以下操作系统上经过测试：

- **Linux**: Ubuntu, CentOS, Debian, Fedora 等主流发行版
- **macOS**: macOS 10.15 及以上版本
- **Windows**: Windows 10, Windows Server 2019 及以上版本

### Web 服务器兼容性

- **Apache**: 2.4 及以上版本
- **Nginx**: 1.14 及以上版本
- **PHP 内置服务器**: 支持
- **Swoole**: 支持（FastD 框架生态）

### 框架兼容性

FastD\Config 可以独立使用，也兼容以下 PHP 框架：

- **FastD**: 原生支持
- **Laravel**: 可通过适配器集成
- **Symfony**: 可通过适配器集成
- **Yii**: 可通过适配器集成
- **CodeIgniter**: 可通过适配器集成

## 安全要求

### 文件权限安全

- 配置文件应设置适当的文件权限
- 敏感配置文件（如包含密码）应限制访问权限
- 避免将配置文件放置在 Web 可访问目录

### 代码安全

- 验证配置文件来源的可信性
- 避免在配置中硬编码敏感信息
- 建议使用环境变量或加密存储敏感配置

## 性能要求

### 处理能力

- **配置文件大小**: 建议单个配置文件不超过 10MB
- **解析速度**: 小于 1MB 的配置文件通常在 100ms 内解析完成
- **内存使用**: 解析过程的内存使用量约为配置文件大小的 3-5 倍

### 并发处理

- 在高并发环境下，建议缓存解析后的配置对象
- 避免重复解析相同的配置文件
- 考虑使用配置中心或配置缓存机制

## 安装前检查

在安装 FastD\Config 之前，请确认以下项目：

### PHP 版本检查

```bash
php -v
```

确保输出显示 PHP 8.2 或更高版本。

### 扩展检查

```bash
php -m | grep json
```

确保 JSON 扩展已启用。

### Composer 检查

```bash
composer --version
```

确保 Composer 已安装并可用。

### 内存限制检查

```bash
php -r "echo ini_get('memory_limit');"
```

建议设置为至少 256M：

```bash
php -d memory_limit=256M -r "echo ini_get('memory_limit');"
```

## 环境准备步骤

### 1. 检查 PHP 版本

```bash
# 检查当前 PHP 版本
php -v

# 如果系统安装了多个 PHP 版本，可能需要指定版本
php8.2 -v  # 或其他版本命令
```

### 2. 安装缺失的扩展

对于 Ubuntu/Debian 系统：

```bash
sudo apt-get update
sudo apt-get install php8.2-json
```

对于 CentOS/RHEL 系统：

```bash
sudo yum install php-json
# 或对于较新版本
sudo dnf install php-json
```

对于 macOS：

```bash
# 使用 Homebrew
brew install php
```

### 3. 验证环境

创建一个简单的 PHP 脚本来验证环境：

```php
<?php
// check_environment.php
echo "PHP Version: " . PHP_VERSION . "\n";
echo "JSON Extension: " . (extension_loaded('json') ? 'Loaded' : 'Not loaded') . "\n";
echo "Memory Limit: " . ini_get('memory_limit') . "\n";

// 测试基本功能
$config = [
    'test' => 'value',
    'nested' => [
        'key' => 'nested_value'
    ]
];

echo "Serialization Test: " . (serialize($config) ? 'Passed' : 'Failed') . "\n";
```

运行检查脚本：

```bash
php check_environment.php
```

## 故障排除

### 常见问题及解决方案

#### 问题1: PHP 版本过低
**症状**: 安装时出现版本不兼容错误
**解决方案**: 升级 PHP 到 8.2 或更高版本

#### 问题2: JSON 扩展缺失
**症状**: 运行时出现 JSON 相关错误
**解决方案**: 安装或启用 JSON 扩展

#### 问题3: 内存限制过低
**症状**: 解析大配置文件时出现内存不足错误
**解决方案**: 增加 PHP 内存限制

#### 问题4: 权限不足
**症状**: 无法读取配置文件
**解决方案**: 检查文件权限设置

通过满足以上环境要求和依赖条件，您可以成功安装和使用 FastD\Config 库来管理应用程序的配置。
