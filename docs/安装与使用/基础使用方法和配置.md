# 基础使用方法和配置

## 快速入门

### 基本使用

最简单的使用方式是创建一个 `FileParser` 实例并加载配置文件：

```php
<?php
require_once 'vendor/autoload.php';

use FastD\Config\FileParser;

// 创建解析器实例
$parser = new FileParser();

// 解析配置文件
$config = $parser->parse('config/app.json');

// 访问配置值
echo $config->get('database.host');
```

### 配置文件示例

创建一个 JSON 配置文件 `config/app.json`：

```json
{
    "database": {
        "host": "localhost",
        "port": 3306,
        "name": "myapp_db",
        "credentials": {
            "username": "root",
            "password": "password"
        }
    },
    "app": {
        "name": "My Application",
        "debug": true,
        "version": "1.0.0"
    }
}
```

## 配置文件格式

### JSON 格式

```json
{
    "database": {
        "host": "localhost",
        "port": 3306
    },
    "features": ["auth", "cache", "logging"]
}
```

使用方法：

```php
$config = $parser->parse('config.json');
echo $config->get('database.host'); // localhost
```

### YAML 格式

```yaml
database:
  host: localhost
  port: 3306
features:
  - auth
  - cache
  - logging
```

使用方法：

```php
$config = $parser->parse('config.yml');
echo $config->get('database.host'); // localhost
```

### INI 格式

```ini
[database]
host = localhost
port = 3306

[features]
0 = auth
1 = cache
2 = logging
```

使用方法：

```php
$config = $parser->parse('config.ini');
echo $config->get('database.host'); // localhost
```

### PHP 格式

```php
<?php
// config.php
return [
    'database' => [
        'host' => 'localhost',
        'port' => 3306
    ],
    'features' => ['auth', 'cache', 'logging']
];
```

使用方法：

```php
$config = $parser->parse('config.php');
echo $config->get('database.host'); // localhost
```

## 配置访问方法

### 使用 get() 方法

```php
use FastD\Config\FileParser;

$parser = new FileParser();
$config = $parser->parse('config.json');

// 访问简单值
$value = $config->get('app.name');

// 访问嵌套值
$nestedValue = $config->get('database.host');

// 使用默认值
$defaultValue = $config->get('nonexistent.key', 'default_value');
```

### 使用数组语法

```php
// 通过数组语法访问
$value = $config['app.name'];
$config['database.host'] = 'new_host'; // 设置值

// 检查键是否存在
if (isset($config['app.name'])) {
    echo $config['app.name'];
}
```

### 使用 Parsed 类直接操作

```php
use FastD\Config\Parsed;

// 直接使用 Parsed 类
$parsed = new Parsed([
    'database' => [
        'host' => 'localhost',
        'port' => 3306
    ]
]);

// 获取值
$host = $parsed->get('database.host');

// 设置值
$parsed->set('cache.driver', 'redis');

// 检查键是否存在
if ($parsed->has('database.host')) {
    echo "Database host is configured";
}
```

## 配置合并

### 合并多个配置文件

```php
use FastD\Config\FileParser;

$parser = new FileParser();

// 解析多个配置文件，它们会被合并
$dbConfig = $parser->parse('config/database.json');
$cacheConfig = $parser->parse('config/cache.yml');
$appConfig = $parser->parse('config/app.php');

// 所有配置都存储在同一个 Parsed 对象中
echo $parser->parsed->get('database.host'); // 从 database.json
echo $parser->parsed->get('cache.driver');  // 从 cache.yml
echo $parser->parsed->get('app.name');     // 从 app.php
```

### 手动合并配置

```php
use FastD\Config\Parsed;

$baseConfig = new Parsed([
    'database' => [
        'host' => 'localhost',
        'port' => 3306
    ]
]);

$envConfig = [
    'database' => [
        'username' => 'root',
        'password' => 'password'
    ],
    'logging' => [
        'level' => 'info'
    ]
];

// 合并配置
$baseConfig->merge($envConfig);

// 结果包含了合并后的配置
echo $baseConfig->get('database.username'); // root
echo $baseConfig->get('logging.level');     // info
```

## 配置修改

### 添加配置项

```php
use FastD\Config\Parsed;

$config = new Parsed([
    'database' => [
        'host' => 'localhost'
    ]
]);

// 添加新的配置项
$config->set('database.port', 3306);
$config->set('cache.enabled', true);
$config->set('features', ['auth', 'cache', 'logging']);
```

### 修改现有配置

```php
// 修改现有值
$config->set('database.host', 'production-server.com');

// 修改嵌套值
$config->set('database.credentials.username', 'admin');
```

### 删除配置项

```php
// 删除简单键
$config->unset('cache.enabled');

// 删除嵌套键
$config->unset('database.credentials.password');

// 使用数组语法删除
unset($config['database.port']);
```

## 配置验证

### 检查配置是否存在

```php
use FastD\Config\Parsed;

$config = new Parsed([
    'database' => [
        'host' => 'localhost',
        'port' => 3306
    ]
]);

// 检查配置是否存在
if ($config->has('database.host')) {
    echo "Database host is configured";
}

// 使用数组语法检查
if (isset($config['database.port'])) {
    echo "Database port is configured";
}
```

### 提供默认值

```php
// 获取配置，如果不存在则返回默认值
$timeout = $config->get('database.timeout', 30);
$debug = $config->get('app.debug', false);
$logLevel = $config->get('logging.level', 'info');
```

## 实际应用场景

### 应用配置管理

```php
<?php
use FastD\Config\FileParser;

class AppConfiguration
{
    private $config;
    
    public function __construct()
    {
        $parser = new FileParser();
        
        // 加载基础配置
        $this->config = $parser->parse('config/app.yml');
        
        // 根据环境加载额外配置
        $environment = $_ENV['APP_ENV'] ?? 'development';
        $parser->parse("config/{$environment}.yml");
        
        $this->config = $parser->parsed;
    }
    
    public function get($key, $default = null)
    {
        return $this->config->get($key, $default);
    }
    
    public function has($key)
    {
        return $this->config->has($key);
    }
}

// 使用
$appConfig = new AppConfiguration();
$dbHost = $appConfig->get('database.host');
$debugMode = $appConfig->get('app.debug', false);
```

### 数据库配置示例

```php
<?php
use FastD\Config\FileParser;

class DatabaseManager
{
    private $config;
    
    public function __construct(string $configFile)
    {
        $parser = new FileParser();
        $this->config = $parser->parse($configFile);
    }
    
    public function getConnectionParams(): array
    {
        return [
            'host' => $this->config->get('database.host', 'localhost'),
            'port' => $this->config->get('database.port', 3306),
            'dbname' => $this->config->get('database.name'),
            'user' => $this->config->get('database.credentials.username'),
            'password' => $this->config->get('database.credentials.password'),
        ];
    }
    
    public function isRedisEnabled(): bool
    {
        return $this->config->get('cache.redis.enabled', false);
    }
}

// 使用
$dbManager = new DatabaseManager('config/database.yml');
$params = $dbManager->getConnectionParams();
```

## 错误处理

### 异常处理

```php
<?php
use FastD\Config\FileParser;

try {
    $parser = new FileParser();
    $config = $parser->parse('nonexistent_config.json');
} catch (Exception $e) {
    echo "配置加载失败: " . $e->getMessage();
    // 使用默认配置
    $config = new \FastD\Config\Parsed([
        'database' => [
            'host' => 'localhost',
            'port' => 3306
        ]
    ]);
}
```

### 配置验证

```php
function validateConfig($config)
{
    $required = ['database.host', 'database.name', 'app.name'];
    
    foreach ($required as $key) {
        if (!$config->has($key)) {
            throw new InvalidArgumentException("缺少必需的配置项: {$key}");
        }
    }
    
    return true;
}

// 使用
try {
    validateConfig($config);
    echo "配置验证通过";
} catch (InvalidArgumentException $e) {
    echo "配置验证失败: " . $e->getMessage();
}
```

## 最佳实践

### 1. 配置分层管理

将配置按功能分层，便于管理和维护：

```php
// database.yml
database:
  host: localhost
  port: 3306
  credentials:
    username: root
    password: password

// cache.yml  
cache:
  driver: redis
  host: localhost
  port: 6379

// app.yml
app:
  name: MyApp
  debug: true
```

### 2. 环境特定配置

为不同环境创建特定的配置文件：

```php
// 根据环境加载配置
$env = $_ENV['APP_ENV'] ?? 'development';
$parser = new FileParser();
$parser->parse('config/base.yml');
$parser->parse("config/{$env}.yml");
```

### 3. 配置缓存

对于频繁访问的配置，考虑缓存机制：

```php
class CachedConfig
{
    private static $cache = [];
    
    public static function get($file, $key, $default = null)
    {
        if (!isset(self::$cache[$file])) {
            $parser = new FileParser();
            self::$cache[$file] = $parser->parse($file);
        }
        
        return self::$cache[$file]->get($key, $default);
    }
}
```

通过这些基础使用方法，您可以有效地在项目中集成和使用 FastD\Config 来管理应用程序配置。
